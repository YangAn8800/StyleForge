## 二、项目事实（以此为唯一依据，禁止编造数字与功能）

**产品**：StyleForge · 提示词海报工坊 —— 用户挑一个风格模板、上传自己的照片，AI 生成「上半保留原片、下半变成艺术化表达」的对照海报。Hackathon 项目，非商业。

**技术栈**：Next.js 16 (App Router) + TypeScript + Tailwind v4 + shadcn/ui；生图走 OpenAI 兼容中转（gpt-image 系列图生图）；产物为 1024×1536 合成图。

**页面清单**（导航栏顺序）：

| 路径 | 名称 | 内容 |
|---|---|---|
| `/` | 首页 | Hero 自动轮播（5 张精选风格，悬浮暂停、圆点切换、点击进详情）、大搜索框+热门标签、风格走马灯、三步流程、双板块入口、精选换一批 |
| `/styles` | 风格库 | 「照片风格化 / 海报生成」双板块 Tab，标签筛选 + `?q=` 搜索，卡片带 NO. 编号 |
| `/compose` | 定制提示词 | 提示词拼装器，拼好可带去生成器 |
| `/create` | 生成器（核心） | 上传照片（拖拽/点选）→ 多选最多 3 个风格（可另加自定义提示词）→ 选输出比例 → 生成 → 结果卡片（下载/查看风格） |
| `/history` | 我的海报 | 服务端共享作品库，按天分组网格、悬浮下载/删除、灯箱看大图 |
| `/community` | 作品广场 | **占位页**（只有邮箱订阅框），不要给特写 |
| `/m` | H5 手机版 | 独立移动流程：拍照/相册上传 → 从收藏风格中选 1 个 → 生成 → 保存图片（含等待样例轮播动画） |
| `/styles/[id]` | 风格详情 | 样例图画廊 + 完整提示词 + 一键复制 |

**关键数字**：风格共 **149 个**（照片风格化 147 + 海报生成模板 2）。

**生成等待**：真实生成一张约 **40–90 秒**（异步任务：提交秒回 → 轮询出图）。录屏时这段时间必须剪掉或快放。

**真实 vs 回退**：若中转余额不足，结果会回退为该风格样例图并显示橙色提示条。演示视频应使用**真实生成**的结果；录制前先试跑一次确认余额。

**共享库**：「我的海报」是服务端共享画廊，所有人生成的图都会进去（录制前可先清理：对不想要的图悬停删除）。

## 三、录屏环境与准备

1. **启动**：项目在 `web/` 目录。已构建则 `cd web && npm start`，浏览器开 `http://localhost:3000`；新机器需先 `npm install && npm run build`。录屏**只用 localhost**（公网隧道地址临时且偶发丢包，不要入镜）。
2. **密钥安全**：`.env.local` 内有中转 API key，**全程不得入镜**（不要打开该文件、不要截到终端环境变量）。
3. **浏览器**：Chrome 全新 profile（无插件、无书签），窗口 1920×1080、缩放 100%、全屏录制；系统外观用浅色（网站是米纸底浅色主题）。
4. **录屏工具**：OBS 或系统录制，**1080p / 30fps 起步**，码率 ≥ 8Mbps；同时录系统声音可关（成片配乐+字幕即可）。
5. **测试照片**：准备 1–2 张清晰、主体完整的照片（人物或静物均可）放桌面，录制时直接拖进上传区。
6. **H5 镜头**：两种做法任选——(a) Chrome DevTools 设备模拟（iPhone 14 Pro, 390×844）；(b) 真手机走隧道 `cloudflared tunnel --url http://localhost:3000` 访问 `/m`（二维码在 `web/public/qr-m.png`，隧道重启后需重新生成）。
7. **录制前热身**：自己先完整跑一遍生成流程，确认服务正常、余额充足、作品库干净。
